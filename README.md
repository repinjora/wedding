# Георгий & Ева — интерактивное приглашение

Одностраничный «маленький фильм»: киновступление → главный кадр → приглашение → дата и место → отсчёт → RSVP.
Стек: React + Vite + Tailwind (сборка в **один статический `dist/index.html`**, поэтому хостится где угодно, включая GitHub Pages).

## 1. Ваша настоящая фотография (важно!)

Положите лучшее фото пары в **`src/assets/couple.jpg`** (можно `.png/.webp`) и пересоберите проект.
Сайт сам стилизует его под зимнюю ночь (холодная цветокоррекция, тёплое свечение, плавное растворение в лесу, туман и снег поверх).
Лучше всего подходит вертикальный кадр 3:4, лица в верхней половине.

Пока файла нет, на главном экране показывается сгенерированная сцена-заглушка (пара со спины, `src/assets/scene.jpg`).
Нейросеть без вашего фото не может сохранить узнаваемость лиц — поэтому настоящий снимок используется как есть, а не «перерисовывается».

## 2. Отправка ответов (RSVP) в Telegram

Форма **не имитирует** отправку: пока ничего не настроено, гость увидит честное сообщение об ошибке.

1. Создайте бота у `@BotFather` → получите токен.
2. Напишите боту любое сообщение (или добавьте его в группу) и узнайте `chat_id` через `@userinfobot`.
3. Выберите вариант:
   - **Безопасный (рекомендуется):** разверните `worker/rsvp-worker.js` на Cloudflare Workers (инструкция в файле) и укажите
     `VITE_RSVP_ENDPOINT=https://ваш-воркер.workers.dev`.
   - **Быстрый:** `VITE_TELEGRAM_BOT_TOKEN` и `VITE_TELEGRAM_CHAT_ID` — токен окажется виден в коде страницы, поэтому используйте отдельного бота.

Значения задаются в `src/config.ts` (поля `RSVP`) или переменными окружения — локально в файле `.env`:

```
VITE_TELEGRAM_BOT_TOKEN=123456:ABC...
VITE_TELEGRAM_CHAT_ID=123456789
```

## 3. Карта

Кнопка «Посмотреть на карте» ведёт на поиск Яндекс.Карт по названию и адресу с официального сайта комплекса.
Хотите точнее — вставьте свою ссылку «Поделиться» в `MAP_URL` (`src/config.ts`).

## 4. Публикация на GitHub

1. Создайте репозиторий и запушьте проект в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. (Опционально) Settings → Secrets and variables → Actions → добавьте `VITE_RSVP_ENDPOINT` или токен/chat_id.
4. Каждый push в `main` публикует сайт — ссылка появится в Settings → Pages.

## Локально

```
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Музыка

Саундтрек (фортепиано, струнные, колокольчики, тихий ветер) **синтезируется в браузере** через Web Audio API — оригинальная композиция
без сторонних файлов и лицензий. Запускается только после нажатия пользователя. На iPhone звук Web Audio может заглушаться
физическим переключателем «Бесшумно» — на новых iOS это обходится автоматически.
